Tijolo 1 — um neurônio é uma continha

entradas × pesos + viés

Um neurônio é uma continha

Entradas vezes pesos, soma tudo, mais o viés. É isso. Não tem mágica nenhuma dentro de um neurônio — tem uma multiplicação e uma soma.

  • peso: o quanto aquela entrada importa
  • viés: o empurrãozinho que desloca o resultado, independente da entrada
# TIJOLO 1: um neurônio é uma continha (entradas × pesos + viés)

def neuronio(entradas, pesos, vies):
    total = 0
    for i in range(len(entradas)):
        total = total + entradas[i] * pesos[i]   # cada entrada vezes seu peso
    total = total + vies                          # o empurrãozinho final
    return total

# Vamos testar com 2 entradas
entradas = [1, 0]
pesos    = [0.5, 0.8]   # a 1ª entrada vale 0.5, a 2ª vale 0.8
vies     = 0.2

resultado = neuronio(entradas, pesos, vies)
print("O neurônio calculou:", resultado)

O que deu quando rodou

O neurônio calculou: 0.7

Conferindo na mão: 1 × 0.5 + 0 × 0.8 + 0.2 = 0.7. A segunda entrada era zero, então o peso 0.8 dela não entrou na conta — entrada zerada não opina, por maior que seja o peso.

O que ainda falta neste tijolo

O resultado saiu 0.7, mas podia ter saído 15 ou -3: essa continha não tem limite. O próximo pedaço é o que espreme esse número para dentro de uma faixa (a sigmoid) — e é isso que deixa vários neurônios empilháveis.
