as seis aulas

Uma manhã, seis erros

As cinco primeiras aconteceram entre 10:00 e 11:09 de um mesmo dia, fotografadas enquanto aconteciam — não para a aula. A sexta apareceu no dia seguinte, na revisão para publicar.

  1. 01 As janelas da máquina

    Um scanner achou 1 porta aberta. O sistema respondeu 20.

    superfície de ataque
  2. 02 O arquivo que rodava sozinho

    Um import em qualquer lugar já abria conexão com o banco.

    o que roda no import
  3. 03 A senha na cara do código

    O pior não é quebrar com a senha dentro. É funcionar.

    credencial nunca mora no código
  4. 04 Onde a senha passa a morar

    Segredo sem endereço novo volta para o antigo.

    variável de ambiente e o .env
  5. 05 O que o Git não pode ver

    No Git não existe apagar. Existe trocar.

    impedir a entrada, não remover depois
  6. 06 O segundo segredo

    Um arquivo sem senha nenhuma dentro — e mesmo assim segredo.

    conferir antes de publicar, sempre

por que este curso existe

O erro tem endereço

A primeira geração do código foi guardada numa pasta original_ia/ antes da revisão, com os defeitos inteiros. Dá para abrir o antes e o depois lado a lado, com um diff, e ver o conserto acontecer.

É por isso que nenhuma linha aqui é exemplo de livro. Cada erro destas seis aulas quebrou alguma coisa de verdade, num computador de verdade, num dia com hora marcada.
